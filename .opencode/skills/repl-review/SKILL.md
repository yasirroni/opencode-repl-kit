# Review a Completed Task

## Instructions

1. Read `AGENTS.md` to understand general agent behavior
2. Read `.opencode/project/OVERVIEW.md` to understand the project
3. Read `.opencode/project/EXECUTED.md` to see what has been done
4. Review the most recently executed task. Check:
   - Does the implementation match what was described in EXECUTED.md?
   - Is the code consistent with the project's patterns (same structure as other language implementations)?
   - Are there any bugs, edge cases, or improvements you notice?
   - Is the documentation (OVERVIEW.md, ARCHITECTURE.md, skill files) still accurate after the changes?

## If You Find Problems

- Describe what you found
- Propose how to fix it
- **Wait for approval before making changes**

## If Everything Looks Good

Confirm that the executed task is solid and nothing needs updating.
